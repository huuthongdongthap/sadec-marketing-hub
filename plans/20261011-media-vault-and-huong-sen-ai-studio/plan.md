3. 100% file JavaScript mới < 200 dòng (tuân thủ nghiêm ngặt quy tắc modularity).
4. Hệ thống Vitest 100% Green (không có bất kỳ test hồi quy nào).
5. Build production (`npm run build`) thành công vào `dist/` và deploy Cloudflare Pages đạt HTTP 200.
